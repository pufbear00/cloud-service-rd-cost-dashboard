# 云服务研发费用看板

来源基线：本地保存的 `api-cost-monitor` main 提交 `0b3c922e174c64235f043d8fd9f31f98aed96561`。保留费用记录模型、服务商采集器结构及通用计算/转换代码；这是隔离后的开发副本，不是线上运行环境的完整镜像。

## 可以运行的部分

用 Python 3.12 在本目录运行 `python3 local_report.py`：默认显示 0 条记录、0 金额，不读取任何其他目录。可用 `--input 自行编写的虚构记录.json` 进行离线汇总，记录字段为 `provider`、`cost_cny`。不附带示例业务数据。

运行自测：`python3 -B -m unittest discover -s tests -v`。上述离线入口和自测仅需 Python 标准库。

## 隔离边界

- 无实际账单、收入流水、预算、账号配置、密钥、证书、历史提交、日志、缓存或原始资料。
- 清除了源码注释中的内部事件、费用数据和员工信息；移除了原有商户分类清单。
- 未复制回填、定时任务、自动推送、线上数据修复与操作脚本。
- 服务商采集器禁止实例化；飞书 CLI 入口关闭；MiniMax 系统钥匙串读取代码已移除。
- 本地入口不读取 dotenv、环境凭据或系统登录账号。包加载时禁止 Python socket 连接；这是防误操作措施，不是操作系统沙箱。
- `lib/`、`providers/` 仍保留部分通用集成源码供开发阅读，但不提供实际联网功能；它们涉及的第三方 SDK 未作为本地入口依赖安装，也未做在线验证。

后续若要恢复外部集成，需要另行审查、授权并配置全新的凭据。不要复制原配置或使用真实账单演示。此副本尚未获得对外发布许可，也未进行完整安全审计。
